## Ringkasan Project

Mini Project ini merupakan pengembangan landing page statis menjadi landing page interaktif menggunakan vanilla JavaScript.

Topik yang digunakan adalah **Lokakarya Web Dasar D3 Teknik Informatika**.

Landing page ditujukan kepada mahasiswa D3 Teknik Informatika yang ingin mempelajari dasar pengembangan web, mulai dari HTML, CSS, hingga JavaScript.

Tujuan utama halaman adalah memberikan informasi mengenai materi lokakarya dan memungkinkan pengguna melakukan interaksi seperti membuka navigasi mobile, memfilter materi, membuka FAQ, mengisi formulir pendaftaran, mengganti tema, dan kembali ke bagian atas halaman.

---

## Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| HTML5 | Struktur dan konten halaman |
| CSS3 | Tampilan, layout, responsive design, dan perubahan visual |
| Vanilla JavaScript | DOM manipulation, event, filter, validasi, dan interaksi pengguna |
| Visual Studio Code | Code editor |
| Live Server | Menjalankan project melalui local development server |
| Chrome DevTools | Pengujian DOM, Console, responsive viewport, dan accessibility |

Project tidak menggunakan framework atau library JavaScript.

Mini project juga tidak menggunakan `fetch`, Promise, atau `async/await`.
